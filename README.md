# Task 3: Employee Salary Analysis

## Description
A Python program written in a Jupyter Notebook to perform numerical data processing on a manually created list of employee salaries.

## Features
* Calculates total salary expenditure using `sum()`.
* Determines average salary.
* Identifies highest and lowest salaries using `max()` and `min()`.
* Compares calculated values against original data.

* Python 3.x
